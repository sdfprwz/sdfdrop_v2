How it works

  • Same WiFi: auto-discovery. Nothing to type.
  • Different network: Room code or QR → relay + WebRTC.
  • Private: P2P first, TURN/relay fallback. Files never stored.

Best of Snapdrop (simple) + PairDrop (rooms) + AirDrop (feel), under sdfdrop branding.

sdfdrop • WebRTC P2P • WS relay fallback • v1.0 P2P ready

❓ Connect devices

  1. Same WiFi (auto): open this page on both devices. No code needed.
  2. Different network: tap 🔗 Room, enter the same code on both, or scan the QR.
  3. Tap a device on the radar to send files or text.

Not seeing each other? Check: same WiFi name (2.4 vs 5 GHz matters on some routers), VPN off, no “client isolation” on hotel WiFi. Then use a Room code — it works everywhere.
